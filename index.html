Hermes Personal Agent

A single-user, non-commercial personal automation tool.

What this application is

Hermes Personal Agent is a private desktop automation tool operated by one individual (the account owner) on a personal computer. It is not a public service, it is not distributed to other users, and it has no customers or commercial purpose.

What it does

The agent helps its single operator stay organized by producing a personal daily summary:

  • Reads the operator's own Gmail inbox to summarize unread messages
  • Reads the operator's own Google Calendar to list upcoming events and detect scheduling conflicts
  • Stores short personal notes in the operator's own Google Drive, and writes project handoff notes into a folder the operator owns

All processing happens locally on the operator's own machine. Everything the application reads or writes belongs to the same person who authorized it.

Google user data

The application accesses Google user data only for the purposes listed above, only for the account that explicitly granted consent, and only while that consent remains in effect. It does not sell, transfer, or share Google user data with any third party. It does not use Google user data for advertising, and it does not use it to train machine-learning models.
