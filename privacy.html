Privacy Policy

Hermes Personal Agent · Last updated: 27 October 2026

This policy explains how Hermes Personal Agent ("the Application") accesses, uses, stores, and shares Google user data. The Application is a private, single-user desktop tool operated by one individual for personal productivity purposes.

1. What Google user data is accessed

  • Gmail — message metadata and content of the operator's own mailbox, used to summarize unread mail. Read and label-modification access only.
  • Google Calendar — the operator's own calendar events, used to list upcoming events and detect overlapping meetings.
  • Google Drive and Google Docs — files created by, or explicitly shared with, the operator's own account, used to store personal notes and project handoff documents.

2. How the data is used

Data is used exclusively to generate a personal summary for the operator and to store the operator's own notes. There is no other purpose.

3. How the data is stored

  • OAuth credentials are stored locally on the operator's own computer, in an encrypted local credential store; they are never transmitted to any third party.
  • Summaries are produced in memory on the operator's machine. Notes the operator asks to keep are written back to the operator's own Google Drive.
  • No copy of Google user data is stored on any server controlled by anyone other than the operator.

4. Sharing and disclosure

The Application does not sell, rent, transfer, or disclose Google user data to any third party. No advertising networks, analytics providers, or data brokers receive any Google user data. The Application has no other users to share data with.

5. Google API Services User Data Policy — Limited Use

The Application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Specifically:

  • Google user data is used only to provide the features described above, which are visible and prominent within the Application.
  • Google user data is not transferred to third parties except as necessary to provide those features, as required by law, or with the operator's explicit consent.
  • Google user data is not used for serving advertisements.
  • Google user data is not used to develop, improve, or train generalized or non-personalized artificial-intelligence or machine-learning models.
  • No humans read the operator's Google user data, other than the operator themself.

6. Data retention and deletion

The Application retains no server-side copy of Google user data. The operator may revoke the Application's access at any time from the Google Account permissions page (myaccount.google.com/permissions), which immediately ends all access. Locally stored OAuth credentials can be deleted from the operator's computer at any time.

7. Security

Access tokens are kept only on the operator's own device. The Application runs on a single machine protected by the operator's own access controls. OAuth scopes are limited to the minimum required for the described features.

8. Changes

Any change to this policy will be published on this page with an updated date.
